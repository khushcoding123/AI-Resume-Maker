# Contributing to AI Resume Maker

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Development Setup

1. Fork the repository
2. Clone your fork: `git clone <your-fork-url>`
3. Run the setup script: `./setup.sh` (Linux/Mac) or `setup.ps1` (Windows)
4. Create a feature branch: `git checkout -b feature/your-feature-name`

## Code Style

- **Frontend**: Follow React/Next.js conventions, use TypeScript, follow ESLint rules
- **Backend**: Follow Node.js/Express conventions, use async/await for async operations
- **Python**: Follow PEP 8 style guide, use type hints where appropriate

## Making Changes

1. Make your changes
2. Test thoroughly
3. Update documentation if needed
4. Commit with clear messages: `git commit -m "Add: feature description"`

## Pull Request Process

1. Update the README.md if needed
2. Ensure all tests pass
3. Submit a pull request with a clear description
4. Wait for code review

## Areas for Contribution

- New resume templates
- Enhanced NLP models
- Additional AI features
- Bug fixes
- Documentation improvements
- Performance optimizations

## Questions?

Open an issue for questions or discussions.
